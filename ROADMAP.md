# SafeRun Roadmap

This roadmap describes the next areas of work for SafeRun. It is directional rather than a promise of release dates.

## Completed

- ✓ npm package sandboxing
- ✓ Docker isolation
- ✓ Security reports
- ✓ Cross-platform installers
- ✓ Audit management

## Next Priorities

- More package managers
- GitHub Action integration
- AI-powered security explanations

## Longer-Term Exploration

- Broader package reputation and vulnerability intelligence
- Deeper sandbox hardening and analysis coverage
- Additional CI/CD workflows

Roadmap priorities may change as security research, user feedback, and platform support evolve.
